# Folder Redact — public release mirror

This repo exists solely to host **public release assets** for [Folder Redact](https://github.com/Pilot-Pixel/folder-redact). The source code lives in the private parent repo; release binaries live here so the Windows installer (`FolderRedact-X.Y-Setup.exe`) can download the app payload via anonymous HTTP at install time.

**Latest release:** see [Releases](https://github.com/Pilot-Pixel/folder-redact-releases/releases).

For full release notes, changelog, and source code, visit [Pilot-Pixel/folder-redact](https://github.com/Pilot-Pixel/folder-redact).
